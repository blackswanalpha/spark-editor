# 0.7.1 — 2026-09-01

One fix: `Shift+Tab` stays in the shell.

- **`Shift+Tab` reached the shell but took the keyboard with it.** Tab and Shift+Tab are focus-navigation keys to the engine before they are anything else, and WebKitGTK traverses on them even when the key press's default is cancelled — so the bytes arrived, focus landed on the terminal panel's own Restart button, and the keystroke after that went nowhere. `preventDefault` is the correct fix and it is not honoured, so the tab order is the lever instead: while a shell holds the keyboard, nothing else inside the terminal panel or the pop-out window is a tab stop. Controls that appear while you are typing are covered too, and everything is restored the moment the surface loses focus, so the panel's buttons stay keyboard-reachable whenever you are not typing into a shell.
