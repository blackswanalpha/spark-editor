# 0.4.0 — 2026-08-30

The terminal grows tabs, the app grows settings, and the explorer stops taking the app down on large projects.

See `CHANGELOG.md` for the full entry.

- **Tabbed terminal sessions** — one tab per shell with a `+` to open another, close buttons and middle-click close. Sessions stay mounted when hidden: `TerminalView` kills its pty on unmount, so an unmounting tab would end the session on every switch. Transitions live in `src/shell/Terminal/sessions.ts`, shared by the docked panel (zustand) and the pop-out window (local state), so "closing the active tab focuses its neighbour" is written once.

- **A session keeps the directory it started in** — previously the panel followed the explorer selection and respawned the shell whenever it moved. With several tabs there is no single directory to follow, and a shell you are typing in must not relocate under you. The explorer now decides where the *next* terminal starts. Privilege is per session too, so the Root toggle respawns one shell and leaves the others alone.

- **Settings** — a gear at the foot of the plugin rail, `Ctrl+,`, and the command palette. Appearance (theme, density, interface text scale), Editor (font size, tab size, word wrap, line numbers), Terminal (font size, line height, cursor style and blink, scroll step, default privilege, mobile preset). Persisted to the existing `settings.json` through the Tauri store with a localStorage mirror, and broadcast over the event bus so the pop-out terminal window follows changes made in the main window. Persisted values are validated on read rather than trusted — the file may predate a key or have been hand-edited, and a terminal font size of 0 makes the grid compute an infinite column count. `CodeEditor` reconfigures through CodeMirror compartments instead of rebuilding, so changing a preference does not discard undo history and cursor position.

- **Mobile view** — a toggle in both the docked panel and the pop-out that pins the terminal surface to a phone viewport. Dimensions only, no device frame. Driven from two CSS custom properties, so leaving mobile restores the size you had dragged the panel to with nothing to remember in JS. The pop-out resizes its own OS window to match, which needed `core:window:allow-set-size` in capabilities — `core:window:default` grants only the read side (`inner-size`, `scale-factor`), so the write was being denied and the toggle was silently CSS-only there.

- **Explorer file watcher no longer takes the app down on large projects** — `watch_path` called `RecursiveMode::Recursive` on the opened folder with no filter, and `notify` followed symlinks. Opening a Flutter project walked `.plugin_symlinks` out into the pub cache: **35,400 directories watched where 248 are useful**, each one logged at TRACE to stdout and to a 40 KB rotating file. `src-tauri/src/watch.rs` now walks the tree itself — skipping build, dependency and VCS directories, never descending a symlink (`DirEntry::file_type` does not resolve them, which also makes a symlink cycle unwalkable), capping at 4096 directories and depth 12, and registering one non-recursive watch per surviving directory. Directories created later are picked up from their own create events. Event flushes cap at 64 changes, past which the host emits a single `bulk` marker and the explorer re-reads its cached listings instead of receiving thousands of IPC messages.

- **Log levels** — `tauri_plugin_log::Builder::default()` logs everything at TRACE to stdout and to a rotating file. Now Info in release and Debug in dev, with `notify`, `notify::inotify`, `tao`, `wry`, `hyper` and `polling` pinned to Warn. Boot went from a flood to 33 lines.

- **The pop-out terminal stays above the editor** — created parented to the main window (`gtk_window_set_transient_for` on Linux, an owner window on Windows, a child window on macOS) instead of sinking behind it on the next click. Not `alwaysOnTop`, which would have put it above every other application. A window manager that refuses the relationship costs the z-order, not the terminal.

- **Terminal tab names come from the directory** — shells title themselves `user@host: dir`, so every tab read `user@…` once truncated to tab width: the one part that distinguishes two shells was the part cut off. Tabs now show the cwd's last segment, with the full path and the shell's own title in the tooltip.

- **Settings sheet is draggable, and lays out correctly** — it was centred with `transform: translate(-50%, -50%)`, which it cannot keep: the entrance animation writes `transform` for its scale and slide, so the centring only held once the animation settled on the identity transform and CSS took over again. Position and size are now real coordinates and `transform` belongs to the animation. Separately, its title and description were two of three children in a grid declared for two rows, so the description absorbed the `1fr` and pushed the section list to the bottom of an otherwise empty sheet; they now share one header, which is also the drag handle.

- **Mobile panel width no longer depends on how many tabs are open** — `width: auto` on a fixed-position box is shrink-to-fit, which takes the width of its widest child, so the header and tab strip decided the panel's width and a few open tabs stretched it back to desktop width with the phone-sized grid stranded at the left edge. The width is stated and the chrome shrinks or scrolls inside it. Default mobile width is 450 (a 390px grid is about 44 columns, which wraps most command output).

- **Removed** — the "System terminal" button in the panel footer.

- **Tests** — 5 covering the settings sheet's drag, viewport clamping, close-button exclusion and grid structure; 1 covering the watcher's skip list and its refusal to follow symlinks. 101 renderer tests and 8 host tests.

- **Version bump** — `0.3.3 → 0.4.0` across `package.json` / `Cargo.toml` / `tauri.conf.json` (+ `Cargo.lock`), enforced by `npm run check:version`.
