# 0.2.0 — 2026-08-28

Desktop icons, setup launchers, and OTA. Consolidates all changes since 0.1.0 into the next minor release.

See `CHANGELOG.md:10` for the full entry. This per-version file mirrors that heading for tooling that expects one file per release (e.g., release notes generators).

## Highlights

- **Launch & setup icons** — regenerated `src-tauri/icons/` via `cargo tauri icon` from `_master.png` (1024). Proper desktop assets: `32x32.png`, `64x64.png`, `128x128.png`, `128x128@2x.png` (256), `icon.png` (512), `icon.icns` (macOS, 64 KB), `icon.ico` (Windows). Bundle `icon` array updated, publisher/category/short/long descriptions added, `createUpdaterArtifacts: true`, and `linux`/`windows`/`macOS` bundle targets wired so installers create correct desktop shortcuts / Start-Menu entries / `.desktop` files.
- **OTA (over-the-air) updates** — `tauri-plugin-updater` (Rust + `@tauri-apps/plugin-updater` JS) wired in `src-tauri/src/lib.rs` + `capabilities/{default,desktop}.json` (updater + `process:allow-restart`). `src/bridge/updater.ts` — `checkForUpdates()` and `checkForUpdatesOnBoot()` with silent boot check (4 s delay) and manual **Help → Check for Updates…** command. `tauri.conf.json:plugins.updater` pubkey `RWQ8…krV` and endpoint `https://github.com/blackswanalpha/spark-book/releases/latest/download/latest.json`. CSP `connect-src` extended to allow GitHub. Release workflow (`.github/workflows/release.yml`) builds `createUpdaterArtifacts` and publishes `latest.json`.
- **File explorer + explorer store** — port `designlabs/labs/explorer.html` to `src/shell/SideBar.tsx` + `src/store/explorer.ts` (lazy `read_dir`, keyboard nav, toolbar, recents, `subscribeToFileChanges`).
- **New editor surfaces** — `src/editor/HtmlPreview/` (live HTML preview) and `src/editor/SvgEditor/` (SVG canvas).
- **Save flows** — `SaveAsModal` + `UnsavedChangesModal` (tests), `src/store/documents.ts` save-as / dirty guard, `src/shell/SideBar` wiring, status-bar integration.
- **CodeEditor language map** — `src/editor/CodeEditor/languages.ts` expanded (1.4 k lines) to cover JS/TS/Python/Markdown/CSS/Go/Rust/SQL/YAML/JSON/HTML with Shiki bridge.
- **UX polish** — `src/App.tsx` MenuBar integration, `src/ui/Icon.tsx` / `DartIcon` / `LangLogo`, `src/shell/SideBar.css` / `CodeEditor.css` refinements, `src/bridge/commands.ts` (create_file/mkdir wrappers + file-watcher).

Known limitations: updater requires `TAURI_SIGNING_PRIVATE_KEY` env for signed releases; first signed `latest.json` is produced by the release workflow. Linux tests: installer creates `.desktop` at `/usr/share/applications/com.sparkbook.app.desktop`; Windows: Start-Menu shortcut + desktop icon via NSIS/Wix.
