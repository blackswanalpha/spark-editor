# 0.3.3 — 2026-08-30

The terminal becomes a real terminal, the explorer pane resizes, and the updater can no longer report a success that did not happen.

See `CHANGELOG.md` for the full entry.

- **Real PTY terminal, xterm.js removed** — the terminal was a simulated shell with seven hardcoded commands. `src-tauri/src/pty.rs` now spawns the actual login shell with `portable-pty` and runs terminal emulation host-side with the `vt100` crate; the renderer receives resolved cell grids over `pty://frame` and paints styled spans (`src/shell/Terminal/TerminalView.tsx`, `src/shell/Terminal/grid.ts`). There is no terminal emulator left in the frontend. `@xterm/xterm` and `@xterm/addon-fit` are removed. Real scrollback, SIGWINCH resize, bracketed paste, DECCKM arrows, control codes, 256-colour + truecolour, and OSC window titles all work because a real shell is driving them.

- **Root shell access** — a header toggle respawns the session through `pkexec`, falling back to `sudo -i`. The OS collects the password; no credential passes through the app. Root sessions get a red border and badge so the elevated one is never mistaken for the normal one. `Ctrl+`` toggles the panel; `view.terminalRoot` toggles privilege from the palette.

- **Explorer resize + collapse** — `src/shell/useSidebarLayout.ts` adds a drag handle between the pane and the editor (180–640px, persisted to localStorage), double-click to reset, snap-closed under 120px, full keyboard control (arrows resize, Enter toggles, Home resets), `Ctrl+B` toggle, and a reveal button when collapsed.

- **Filesystem watching** — `watchPath`/`unwatch_path` and the `file:changed` subscription were wired up on the client with no host command behind them, so the tree never noticed changes made outside the app. `src-tauri/src/watch.rs` implements them with `notify`, coalescing bursts over 120ms.

- **Updater: phantom updates are now impossible** — `tauri-action` writes `latest.json` from `tauri.conf.json`, not from the tag, so tagging `v0.3.3` without bumping that file ships a release *named* 0.3.3 that advertises 0.3.2 — clients update "successfully" and stay put. `scripts/check-version-sync.mjs` fails the build when the tag and the three manifests disagree (wired into `ci.yml` and `release.yml`); the client refuses any manifest not strictly newer than the running binary; the UI reads its version from the running binary via `getVersion()` instead of build-time `package.json`; `src-tauri/src/update_env.rs` reports the install medium using `bundle_type()` — the same value `tauri-plugin-updater` keys off — and refuses to download when no installer can apply; and every install writes a receipt that `verifyPendingUpdate()` checks on the next boot, so a silent failure is reported instead of hidden.

- **Races, leaks, breakages** — document-store mutators spread `s.docs[id]` unguarded, so a debounced editor callback landing after a tab close resurrected a ghost document or crashed on `s.history[id].past`; `saveDocument` marked clean from a pre-write snapshot, dropping edits made during the write; the SideBar zustand selector returned a fresh object literal on every read so the whole tree re-rendered on any store write; `loadChildren` was called during render; `copyTo` looked the source up in the destination's listing so cross-directory folder copies rendered as files; the `file:changed` ancestor walk computed its separator index once outside the loop and skipped levels; a stale-generation load left rows spinning forever; `React.lazy()` inside a component body remounted the terminal window every render; the CodeEditor language compartment was keyed on `doc.raw` and re-parsed the whole document on every keystroke, and store-side changes (undo/redo, Revert File) never reached the view; toast timers leaked past unmount.

- **CI** — `.github/workflows/develop.yml:98` had an unquoted `${{ }}` inside a YAML flow mapping, so the file never parsed and every run of that workflow died at startup with "workflow file issue" and 0s duration. Quoted.

- **Version bump** — `0.3.2 → 0.3.3` across `package.json` / `Cargo.toml` / `tauri.conf.json` (+ `Cargo.lock` synced), now enforced by `npm run check:version`.
