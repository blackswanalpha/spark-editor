Red theme (dark crimson) ships alongside the boot-experience work: real-stage splash, first-run welcome wizard + onboarding, loader overlay, and the updater missing-platform fix.

See `CHANGELOG.md:22` for the full entry.

- **Red theme** — `src/theme/ThemeProvider.tsx:12` adds `red` to `ThemeId`/`ORDER`/`resolveTheme` (5 themes + system), `src/theme/tokens.css:299` new `:root[data-theme="red"]` dark crimson theme (bg #1c0a0e, surfaces #260f13→#57202b, accent #ef5350), `src/shell/TitleBar.tsx:30` adds `red` to the theme menu + 6th swatch (3×2 mini-grid fills exactly), `src/shell/TitleBar.css:95` `.titlebar__swatch--red` #ef5350, `src/shell/WelcomeWizard.tsx:25` Red in the wizard theme pick ("Crimson night"). - **Boot experience** (from `feature/boot-experience-screens`) — splash driven by real boot stages with `v{version}` meta (`src/shell/SplashScreen.tsx`, `src/version.ts`); first-run welcome wizard + onboarding empty state (`src/shell/WelcomeWizard.tsx`, `src/shell/Onboarding.tsx`, `src/shell/firstRun.ts`); `LoaderOverlay` + reduced-motion support (`src/ui/Loader.tsx`).

- **Updater fix** — `src/bridge/updater.ts` `classifyUpdaterError()` treats a missing platform in `latest.json` (e.g. `linux-x86_64`) as "No update available for this platform yet" instead of "Update check failed"; `.github/workflows/release.yml` installs `libfuse2`, pins `--bundles appimage,deb` on Linux, and `verify-ota` fails the release if `linux-x86_64` is absent from `latest.json`.

- **Version bump** — `0.3.1 → 0.3.2` across `package.json`/`Cargo.toml`/`tauri.conf.json` (+ `Cargo.lock` synced).
